# FRP Auto Deploy

**VPN, 클라이언트측 인바운드 방화벽 개방, 수동 FRP 설정 없이 NAT/방화벽 뒤 시스템에 원격 접속합니다.**

FRP Auto Deploy는 공식 `fatedier/frp` 바이너리를 그대로 터널 엔진으로 사용하고, 그 위에 안전한 등록, 영구 CLIENT ID, 서비스/포트 관리, 진단, 백업/복구와 `frpctl` 운영 CLI를 추가합니다.

## 어떤 문제를 해결하나요?

고객/파트너 환경의 서버에 원격 기술지원을 할 때 VPN 구성이나 방화벽 NAT 변경을 요청하는 것은 번거롭고 시간이 오래 걸립니다. FRP Auto Deploy에서는 원격 클라이언트가 서버 쪽으로 **아웃바운드 연결**을 만들기 때문에, 일반적인 환경에서는 클라이언트 자체에 공인 IP나 인바운드 포트 포워딩이 필요하지 않습니다.

## 빠르게 이해하기

```text
인터넷 / 관리자
      |
      v
FRP Auto Deploy 서버 (공인 진입점)
      ^
      |  클라이언트가 시작하는 FRP 터널
      |
+-----+-------------------+
|                         |
클라이언트 A              클라이언트 B
NAT 뒤                    NAT 뒤
|                         |
로컬 SSH/HTTPS            내부 LAN의 SSH/HTTP
```

## 주요 기능

- Zero-Touch 또는 수동 Enrollment Code 등록
- 호스트명/IP 변경과 무관한 영구 CLIENT ID
- SSH, HTTP, HTTPS passthrough, Custom TCP
- 한 클라이언트에 여러 서비스 등록
- 클라이언트가 접근 가능한 다른 LAN 호스트의 서비스 게시
- 공개 서비스 포트의 영구 예약
- `disable`, `revoke`, `release`의 명확한 수명주기 분리
- `frpctl doctor`를 통한 읽기 전용 진단
- 백업/복구 및 안전한 업데이트
- Direct / Enterprise single-443 배포 모드
