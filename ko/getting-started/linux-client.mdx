# Linux 클라이언트

현재 stable 클라이언트 범위는 **Linux/systemd**입니다.

## 권장: Zero-Touch

서버 관리자가 초기 SSH 프로필을 정하고 한 줄 명령을 발급합니다.

```bash
sudo frpctl create enrollment \
  --one-line \
  --ssh \
  --ssh-user aella \
  --label branch-a
```

원격 Linux 시스템에서 생성된 명령을 한 번 실행합니다.

## 수동 Enrollment Code

원격 사용자가 설치 과정에서 서비스 종류와 타깃을 선택해야 한다면 서버에서:

```bash
sudo frpctl create enrollment
```

생성된 설치 명령을 원격 시스템에서 실행하고, 프롬프트에 Enrollment Code를 입력합니다.

## 설치 후 확인

클라이언트에서:

```bash
sudo frpctl show version
sudo frpctl show status
sudo frpctl show services
sudo frpctl show info
sudo frpctl doctor
```

서버에서:

```bash
sudo frpctl show clients
sudo frpctl show client <CLIENT-ID>
```

## 서비스 변경

클라이언트에서 서비스 변경은 staged 상태로 관리됩니다.

```text
add service
set service <service-id> target-host <host>
set service <service-id> target-port <port>
apply
```

잘못 수정했다면 `apply` 전에 `discard`할 수 있습니다.

## 중요한 점

- 재부팅만으로 재등록할 필요가 없습니다.
- 일반 업데이트는 CLIENT ID와 공개 포트 예약을 유지하도록 설계되어 있습니다.
- 로컬 클라이언트 삭제와 서버 측 `release`는 같은 작업이 아닙니다.
