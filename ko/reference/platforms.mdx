# 지원 플랫폼 & 제한

## Stable 범위

현재 stable 지원 범위는 **Linux/systemd**입니다.

자동 portability 검증에는 다음 계열이 포함됩니다.

- Ubuntu 22.04 / 24.04
- Rocky Linux 8 / 9
- AlmaLinux 9
- Amazon Linux 2023 / 2

실제 VM 검증과 container portability 검증은 같은 의미가 아닙니다. SELinux Enforcing, ARM64 systemd, 일부 구형 OpenSSL 환경은 별도 검증 대상으로 취급됩니다.

## Windows / macOS

Windows와 macOS 클라이언트 자동화는 개발 대상이지만 현재 stable 지원 범위로 표시하지 않습니다.

## 제품 설계 범위

FRP Auto Deploy는 **몇 대에서 몇십 대 정도의 시스템**을 간단하게 관리하는 것을 목표로 합니다. 수백 대 이상의 대규모 fleet orchestration 제품을 목표로 하지 않습니다.

## 주요 제한

- TCP 서비스만 게시
- 외부 방화벽/NAT/cloud security group 자동 설정 없음
- OS 계정, 패스워드, SSH key 자동 관리 없음
- bootstrap script는 checksum 검증 대상이지만 프로젝트 자체 cryptographic signature는 현재 제공하지 않음
- HTTPS 서비스는 TLS termination이 아니라 TCP passthrough
