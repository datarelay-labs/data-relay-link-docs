# 라이선스

Data Relay Link는 **소스 공개형(source available) 소프트웨어이며 오픈소스가 아닙니다**. 별도 표시가 있는 파일이나 제3자 구성요소를 제외한 현재 배포본에는 **Data Relay Source Available License 1.0**이 적용됩니다.

<Note>
정식 라이선스 전문은 GitHub의 [`datarelay-labs/data-relay-link` LICENSE 파일](https://github.com/datarelay-labs/data-relay-link/blob/main/LICENSE)이 기준입니다. 이 페이지는 이해를 돕기 위한 요약이며 정식 라이선스 조항을 대체하지 않습니다.
</Note>

## 무료로 허용되는 사용

다음 용도로 Data Relay Link를 무료로 사용할 수 있습니다.

- 개인 사용
- 교육 및 비상업적 연구
- 평가 및 테스트
- 기업·기관의 내부 상업적 사용
- 허용된 목적을 위한 내부 소스코드 수정
- 고객이 직접 통제하고 사용하는 고객 소유 환경에 설치
- 고객 소유 환경에 대한 유상 설치, 통합, 마이그레이션, 유지보수, 교육 또는 지원 서비스. 단, Data Relay Link 자체를 재판매하거나 관리형 서비스로 운영해서는 안 됩니다.

## 제품화는 허용되지 않습니다

Data Relay Labs의 별도 서면 상용 라이선스가 없으면 다음 행위를 할 수 없습니다.

- Data Relay Link 재판매 또는 재라이선스
- 원본 또는 수정본을 독립 상용 제품으로 재배포
- Data Relay Link 또는 소스코드의 상당 부분을 상용 제품이나 어플라이언스에 OEM, 임베딩, 번들 또는 통합
- 상업적 제품화를 목적으로 이름 변경, 리브랜딩, 화이트라벨 또는 포크
- Data Relay Link 기능을 제3자에게 SaaS, MSP, 호스팅, 공유 또는 멀티테넌트 서비스로 제공
- Data Relay Link 또는 소스코드의 상당 부분을 이용해 경쟁 또는 대체 가능한 유사 제품이나 서비스를 개발·개선·유지
- 저작권, 라이선스, 출처 또는 상표 고지 제거 또는 은폐
- 이 프로젝트를 OSI 승인 오픈소스 소프트웨어로 표현

## 예시

| 사용 시나리오 | 허용 여부 |
|---|---|
| 회사 내부 서버에서 Data Relay Link 사용 | 허용 |
| 회사 내부 환경에 맞게 소스를 수정하여 사용 | 허용 |
| 고객 소유 환경에 설치하고 고객이 직접 운영 | 허용 |
| 해당 고객 소유 환경에 대한 설치, 마이그레이션, 지원 또는 교육 비용 청구 | 허용 |
| Data Relay Link를 포크하고 이름을 바꿔 다른 제품으로 판매 | 허용 안 됨 |
| Data Relay Link 코드를 상용 보안·연결 제품에 포함 | 허용 안 됨 |
| Data Relay Link 기능을 SaaS 또는 MSP 서비스로 판매 | 허용 안 됨 |
| 소스를 이용해 경쟁·대체 제품을 개발 또는 개선 | 허용 안 됨 |

## 별도 상용 라이선스

재판매, OEM/임베딩, 화이트라벨, 상업적 재배포, 파생 상용 제품, SaaS/MSP/호스팅 제공, 경쟁 제품 관련 권리 또는 기타 제품화가 필요한 경우 **Data Relay Labs가 별도로 서면으로 부여하는 상용 라이선스**가 필요합니다.

## 왜 Source Available인가요?

이 라이선스는 제품화, 경쟁 제품, SaaS/MSP 사용에 제한을 둡니다. 이러한 사용 제한은 OSI Open Source Definition과 호환되지 않으므로 Data Relay Link는 **오픈소스가 아니라 Source Available**로 표기합니다.
