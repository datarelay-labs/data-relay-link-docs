# Zero-Touch 등록

Zero-Touch는 서버 관리자가 초기 클라이언트 프로필을 정하고, 원격 사용자에게 **한 줄 명령**만 전달하는 권장 등록 방식입니다.

## SSH 예시

서버에서:

```bash
sudo frpctl create enrollment \
  --one-line \
  --ssh \
  --ssh-user aella \
  --label branch-a
```

`aella`는 원격 시스템에 이미 존재하는 SSH 계정이어야 합니다.

FRP Auto Deploy는 다음을 자동으로 하지 않습니다.

- OS 사용자 생성
- SSH 서버 설치/활성화
- 비밀번호 설정
- SSH 키 생성
- `authorized_keys` 수정

## 생성된 명령 취급

생성된 명령에는 단기 bootstrap credential이 포함될 수 있습니다. 공개 이슈, 공개 채팅, 일반 로그에 남기지 마세요.

## 실행 후 확인

서버에서:

```bash
sudo frpctl show clients
sudo frpctl show enrollments
```

성공한 클라이언트는 영구 CLIENT ID를 받습니다.

## Short URL

현재 stable v2.1.2에서는 서버가 출력하는 `zt1` 형태를 그대로 사용하세요. 2.1.3 개발 트리에서는 operator-managed public TLS hostname을 사용하는 더 짧은 URL 흐름이 추가되고 있습니다.

```bash
curl -fsSL https://bootstrap.example.com/i/<opaque-ticket> | sudo bash
```

이 기능은 DNS, 공개 신뢰 TLS, reverse proxy가 별도로 필요하며 stable v2.1.2 기능으로 가정하면 안 됩니다.
