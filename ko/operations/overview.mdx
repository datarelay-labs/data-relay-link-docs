# 운영 개요

일상 운영에서 가장 중요한 원칙은 **먼저 상태를 읽고, 필요한 변경만 수행하고, 변경 뒤 실제 서비스까지 검증하는 것**입니다.

## 어떤 작업을 해야 하나요?

```mermaid
flowchart TD
    A[운영 작업] --> B{목적은?}
    B -->|상태 확인| C[show status / doctor]
    B -->|소프트웨어 갱신| D[Update]
    B -->|장애 대비| E[Backup]
    B -->|복구| F[Restore]
    B -->|서비스 잠시 중지| G[Disable]
    B -->|Identity 차단| H[Revoke]
    B -->|Public port 반환| I[Release]
    B -->|장애 원인 분석| J[Troubleshooting]
```

## 안전한 운영 루프

```mermaid
flowchart LR
    O[Observe] --> D[Diagnose]
    D --> C[Change]
    C --> V[Verify]
    V --> O
```

1. **Observe** — `show status`, `show clients`, `show services`로 현재 상태를 확인합니다.
2. **Diagnose** — `doctor`와 네트워크/target reachability를 확인합니다.
3. **Change** — 필요한 최소 변경만 수행합니다.
4. **Verify** — 서버/클라이언트 상태뿐 아니라 실제 public endpoint에서 서비스도 테스트합니다.
