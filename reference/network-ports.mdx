# Network Ports

FRP Auto Deploy publishes TCP services. The default published service range is **6000-6098**.

## Direct mode

| Purpose | Default public TCP | Default listen TCP |
| --- | ---: | ---: |
| FRP control | 443 | 443 |
| Enrollment / management HTTPS | 6099 | 6099 |
| Published services | 6000-6098 | 6000-6098 |

TCP/22 is optional for your own administrative SSH access to the server and is not part of the FRP Auto Deploy product path.

## Enterprise single-443

| Purpose | Public TCP | Internal/backend TCP |
| --- | ---: | ---: |
| HTTPS enrollment + FRP control over WSS | 443 | allocator 6099 + frps 7000 on loopback |
| Published services | 6000-6098 | 6000-6098 |

In single-443 mode, the allocator backend and FRP control backend are not intended to be Internet-exposed.

## NAT deployments

The public control/enrollment ports can be translated by an external firewall if necessary. Published service ports should normally remain 1:1 so the server's persistent port reservation matches the Internet-facing endpoint.

## TCP only

The current core product scope is TCP: SSH, HTTP, HTTPS passthrough, and custom TCP. UDP is not part of the current stable core scope.
