# Release Status

FRP Auto Deploy separates the immutable stable release from the mutable `main` branch.

| Published stable release | **v2.2.1** |
| Project version | **2.2.1** |
| Pinned / tested FRP | **v0.71.0** |
| Stable install source | immutable `v2.2.1` tag |
| Release commit | `19d4b6fb8a9bee2d477ace6f5c3ed70310e7ea8f` |
| Qualified candidate | `2140be5b6342c3651c16a458f8ea1bc9b577d992` |
| Full Real E2E | **PASS / PASS on the same exact candidate HEAD** |
| `main` | may advance with post-release development or docs-only commits |

The qualified candidate and the v2.2.1 release tree were identical. Published v2.2.0 remains an immutable historical release and was not retagged.

## Use stable for field installs

For a normal installation, use the immutable v2.2.1 release tag:

```bash
curl -fsSL \
  https://raw.githubusercontent.com/datarelay-labs/frp-auto-deploy/v2.2.1/dist/bootstrap-server.sh \
  | sudo bash
```

Do not replace the immutable tag with mutable `main` unless you intentionally want development-channel behavior.

## FRP version policy

The project does not automatically install the newest upstream FRP. The upstream binary is pinned, tested, and validated before adoption. `show upstream` is informational.

Current pinned FRP:

```text
0.71.0
```

## Stable platform status

v2.2.1 includes Real E2E validation for **Ubuntu 24 physical, Rocky Linux 8.10, Rocky Linux 9.4, Amazon Linux 2023, macOS Apple Silicon, and Windows 10 / PowerShell 5.1**.

Amazon Linux 2 remains **container/CI portability only**, and PowerShell 7 is **CI validated** unless a real test host actually has `pwsh` installed. See [Supported Platforms](/reference/platforms) for the exact validation matrix.
