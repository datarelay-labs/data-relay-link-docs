# Documentation image policy

- OCI Console screenshots come from the Owner-provided Word deployment guide.
- Preserve the original pixel dimensions; do not downscale screenshots.
- Lossless WebP is allowed only when pixels remain identical to the source PNG.
- Place one screenshot at the corresponding UI step; do not combine multiple console screens into a montage.
- Do not use generated or unrelated third-party screenshots in place of the Owner-provided originals.
